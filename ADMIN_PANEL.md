# 🎯 Админ-панель A-FRAME KG — Документация

## ✅ Что создано

Полная админ-панель для управления платформой бронирования A-frame домиков.

---

```

│   └── [id]/               — Детали бронирования (TODO)
├── reviews/

├── regions/
│   └── page.tsx            — Управление регионами
├── amenities/
```

## 🚀 Запуск

```bash
# 1. Убедись что БД настроена и заполнена
npm run db:push
npm run db:seed

# 2. Запусти приложение
npm run dev

# 3. Открой админ-панель
http://localhost:3000/admin
```

## 📊 Основные страницы

### 1. Дашборд (`/admin`)
- Статистика: пользователи, домики, бронирования, доход
- Последние бронирования
- Быстрые действия

### 2. Пользователи (`/admin/users`)
- Список всех пользователей
- Фильтрация по роли и статусу
- Детальная информация о каждом пользователе
- История бронирований, отзывы, избранное

### 3. Владельцы (`/admin/owners`)
- Список всех владельцев домиков
- Проверка и верификация владельцев
- Статус проверки профиля
- Количество домиков каждого владельца

### 4. Домики (`/admin/cabins`)
- Список всех домиков
- Модерация статусов (DRAFT, PENDING, PUBLISHED, BLOCKED)
- Информация о владельце, локации, цене
- Статистика бронирований и отзывов

### 5. Бронирования (`/admin/bookings`)
- Все бронирования в системе
- Фильтрация по статусу
- Информация о пользователе, домике, датах
- Управление статусами бронирований

### 6. Отзывы (`/admin/reviews`)
- Модерация отзывов
- Публикация/скрытие отзывов
- Просмотр полного текста и рейтинга

### 7. Регионы (`/admin/regions`)
- Список регионов Кыргызстана
- Управление активностью
- Количество локаций в регионе

### 8. Удобства (`/admin/amenities`)
- Справочник удобств (Wi-Fi, кухня...)
- Статистика использования
- Управление активностью

### 9. Статистика (`/admin/statistics`)
- Пользователи по ролям
- Домики по статусам
- Бронирования по статусам с доходом
- Топ-5 популярных домиков
- Журнал активности

### 10. Платежи (`/admin/payments`)
- История всех платежей
- Статусы транзакций
- Информация о бронированиях

### 11. Уведомления (`/admin/notifications`)
- Отправленные уведомления
- Статус прочтения
- Создание новых уведомлений

### 12. Настройки (`/admin/settings`)
- Конфигурация системы
- Комиссия сервиса
- Модерация и автоматизация
- Опасные операции (очистка кэша, экспорт БД)

## 🔐 API Endpoints

### Пользователи
```
GET    /api/admin/users/[id]       — Получить пользователя
PATCH  /api/admin/users/[id]       — Обновить (статус, роль)
DELETE /api/admin/users/[id]       — Удалить пользователя
```

### Домики
```
PATCH  /api/admin/cabins/[id]      — Изменить статус
DELETE /api/admin/cabins/[id]      — Удалить домик
```

### Отзывы
```
PATCH  /api/admin/reviews/[id]     — Модерация (PENDING → PUBLISHED/HIDDEN)
DELETE /api/admin/reviews/[id]     — Удалить отзыв
```

### Бронирования
```
GET    /api/admin/bookings/[id]    — Детали бронирования
PATCH  /api/admin/bookings/[id]    — Изменить статус
```

### Статистика
```
GET    /api/admin/stats             — Общая статистика
```
